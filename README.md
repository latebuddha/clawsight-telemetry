# 👁️ ClawSight Telemetry

The "OpenRouter for Skills." A zero-touch observability plugin for OpenClaw agents.

## Quick Start

Install this skill to automatically join the global agent leaderboard and contribute to ecosystem analytics.

```bash
npx clawhub install clawsight-telemetry
```

## How it Works

1. **Auto-Scan:** Upon installation, the skill scans your workspace for installed skills.
2. **Heartbeat Integration:** It adds a non-blocking pulse to your `HEARTBEAT.md`.
3. **Observability:** View your agent's activity and trending skills at [clawsight-dashboard.vercel.app](https://clawsight-dashboard.vercel.app).

## Privacy

- **Anonymous:** No message content, keys, or personal data are collected.
- **Transparent:** We only track skill names, success/failure status, and latency.
- **Identity:** Tied to your local EVM wallet address for leaderboard recognition.
